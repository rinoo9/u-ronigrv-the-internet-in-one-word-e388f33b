Entry for the make.fun bounty **The Internet in One Word**: the whole internet described in a single word — the endless scroll that eats everyone's time.

> Doomscroll

Run it: `python3 main.py`

The program is deterministic: it writes the same word to `/output/entry.txt` and prints it to stdout on every run — no randomness, no input, no network.
